# Francisco Escalona - Portfolio Website

A modern, responsive portfolio website showcasing professional experience, skills, projects, and recommendations.

## Features

- **About Me Section**: Introduction with professional background and experience
- **Skills Showcase**: Interactive skill cards displaying technical expertise
- **Projects Portfolio**: Detailed descriptions of key projects and achievements
- **Recommendations**: Display of professional recommendations with an interactive form to add new ones
- **Smooth Scrolling Navigation**: Seamless navigation between sections
- **Scroll-to-Top Button**: Convenient button to return to the top of the page
- **Responsive Design**: Fully responsive layout that works on all devices

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with CSS variables, flexbox, and grid layouts
- **JavaScript (Vanilla)**: Interactive functionality and form handling

## File Structure

```
HtmlPortfolioWebsite/
├── index.html          # Main HTML structure
├── styles.css          # Styling and responsive design
├── script.js           # Interactive functionality
└── README.md           # Project documentation
```

## Usage

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required - it's a pure HTML/CSS/JavaScript website

## Local Development

Simply open `index.html` in your preferred web browser. For a better development experience, you can use a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.
